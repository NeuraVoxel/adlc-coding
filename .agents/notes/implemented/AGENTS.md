# Supplement to AGENTS.md — `implemented/`

Environment instructions, English-only by policy, granting this file the same
exemption as the root `AGENTS.md`. It governs the notes in this directory and
nothing else.

## Stay current with what shipped

When a later change moves a file, renames a package, script, or symbol, or
changes a default this decision named, the same change rewrites those facts in
the note that owns the decision. Rewrite the stale fact in place — do not append
a correction, a changelog section, or "previously, …" narration under the old
claim. The tree is a record of what is true now; git history is where dial
settings belong.

## This is not a license to rewrite the decision

Updating facts is required. Changing what was decided is not: reversing,
replacing, or widening a decision means a new note that supersedes this one,
with both cross-linked. A note whose `## Decision` quietly flips to its opposite
leaves no record of what was given up, and no reader can tell which version was
ever true.
