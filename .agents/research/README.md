# Research notes

This directory holds research notes for this repository: the findings of an investigation against primary sources, written down so a later decision can cite them instead of redoing the reading.

## Boundary

- **Not Agent Notes.** Nothing here enters `.agents/notes/`, uses the Agent Note header or skeleton, or counts as a decision record.
- **Not learning notes.** [`.agents/learning/`](../learning/README.md) records reflection on this repository and this session — what happened, what to do differently. A research note is the opposite direction: evidence gathered from *outside*, about a subject this repository does not own, kept because a claim needs a source.
- **Not a todo entry.** Uncommitted sparks queue in [`.agents/inbox/`](../inbox/README.md); research that surfaces one links over rather than listing it.
- **Not consumer documentation.** Durable contracts for adopters live in `README.md`, `docs/`, or Agent Notes — never here.

## Entry language

Write in Chinese by default; terms, paths, and commands stay English.

## Layout

Files are named `yyyy-mm-dd-slug.md` (the date is when the research was first written). Each note names the question it answers and cites the source of every claim — a claim whose source is not named does not belong in this directory.

## Lifecycle

When a note's durable facts have been absorbed into an Agent Note or shipped documentation, delete the note or mark it absorbed at the top, so this directory never becomes a second authority.
