# 研究笔记

本目录存放对本仓库的研究笔记：针对一手来源调查所得的结论，写下来以便后续决策直接引用，而不必重做一遍阅读。

## 边界

- **不是 Agent Note。** 任何内容都不进 `.agents/notes/`，不使用 Agent Note 的 header 或骨架，也不构成决策记录。
- **不是学习笔记。** [`.agents/learning/`](../learning/README.md) 记录的是对本仓库、本次会话的反思——发生了什么、下次怎么做。研究笔记方向相反：从**外部**取证，主题不归本仓库所有，留存理由是有结论需要来源。
- **不是待办入口。** 未承诺的灵感排队在 [`.agents/inbox/`](../inbox/README.md)；研究中冒出的灵感链过去，而不是在此列成清单。
- **不是消费者文档。** 面向采用者的持久合同写在 `README.md`、`docs/` 或 Agent Note——绝不写在这里。

## 条目语言

默认用中文写；术语、路径与命令保留英文。

## 布局

文件命名 `yyyy-mm-dd-slug.md`（日期为首次撰写日）。每条笔记写明它所回答的问题，并为每条结论标注来源——没有标注来源的结论不属于本目录。

## 生命周期

当笔记中的持久事实已被 Agent Note 或已发布文档吸收后，删除该笔记，或在文首标明已吸收——本目录绝不成为第二套权威。
